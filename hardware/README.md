## What counts as open hardware here

Published design files (STEP, STL or editable CAD), a bill of materials, and a license that allows modification and redistribution. Entries state the hardware license where the project declares one. A robot with only an open SDK belongs in [software/middleware-and-control.md](../software/middleware-and-control.md).
