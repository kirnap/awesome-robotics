## Object pose estimation

- [AprilTag](https://github.com/AprilRobotics/apriltag) - Visual fiducial marker detection and pose estimation with a small C library (BSD-2-Clause).
- [FoundationPose](https://github.com/NVlabs/FoundationPose) - NVIDIA's unified 6D object pose estimation and tracking for novel objects, with or without a CAD model (NVIDIA source code license, noncommercial).

## Grasp detection

- [GraspNet](https://github.com/graspnet/graspnet-baseline) - End-to-end 6-DoF grasp pose detection from point clouds with the GraspNet-1Billion benchmark (academic noncommercial license).

## Point clouds and 3D reconstruction

- [nvblox](https://github.com/nvidia-isaac/nvblox) - CUDA library for real-time 3D reconstruction and distance-field maps for robot planning (Apache-2.0).
- [Open3D](https://github.com/isl-org/Open3D) - C++ and Python library for point-cloud processing, registration, 3D reconstruction and visualization (MIT).
- [Point Cloud Library (PCL)](https://github.com/PointCloudLibrary/pcl) - C++ library for filtering, registering, segmenting and reconstructing point clouds (BSD-3-Clause).
